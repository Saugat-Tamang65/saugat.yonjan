## 🔐 Projects

### 1. Password Strength Checker and Generator
**Tech:** Python

A command-line tool that checks how strong a password is and can also generate a secure random one.

**Features**
- Scores a password out of 6 based on length, lowercase, uppercase, numbers and special characters
- Gives clear tips on how to improve a weak password
- Flags very common passwords
- Generates random passwords (8 to 64 characters) using Python's `secrets` module, which is cryptographically secure

**How to run**
```bash
python password_tool.py
```

📂 Repository: [password-tool](https://github.com/Saugat-Tamang65/password-tool)

### 2. Network Port Scanner
**Tech:** Python, Socket Programming

A simple TCP port scanner that checks which ports are open on a host and shows the service running on each one.

**Features**
- Scans a custom range of ports (1 to 65535)
- Identifies common services, for example port 80 as http and port 22 as ssh
- Uses multithreading to scan many ports at once, which is much faster
- Includes input validation and error handling

**How to run**
```bash
python port_scanner.py
```

> ⚠️ **Use responsibly:** only scan your own computer (`127.0.0.1`) or devices you have permission to test. Scanning other systems without permission may be illegal.

📂 Repository: [port-scanner](https://github.com/Saugat-Tamang65/port-scanner)
